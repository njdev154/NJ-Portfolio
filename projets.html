CIBanque

Prototype d'interface bancaire, un projet personnel inspiré des services financiers accessibles en Côte d'Ivoire (FCFA, Orange Money, Wave, MTN MoMo). Site 100% statique, sans serveur : les données sont gérées avec localStorage et la connexion/les transactions sont simulées.

HTML CSS JavaScript

Ce que j'ai travaillé

  • Structure HTML de 8 pages liées entre elles
  • Mise en page CSS (mise en forme des tableaux de bord, formulaires)
  • Interactions JavaScript simples (connexion, historique simulés)

Ce que j'ai appris

  • Organiser un projet multi-pages de façon cohérente
  • Stocker des données côté navigateur avec localStorage
  • Adapter une interface au contexte local (FCFA, mobile money)
